# v2.4.0 - Freebuild Drop
==========================
<@&1243289354957492386> 
**Features**
- Added Freebuild map (next to Wilds)
- Freebuild is a special zone designed to make it easier to get into building as a new player
  - You are given most of the Building Starter Pack for free (just for that room)
  - There's no pasting, so it's all about building casually and messing around
  - Occasionally, ||special storms will roll in|| which ||spawn in extra blocks and gadgets to use!||

- Added Community World categories
  - You can put your Community World into a category to make it easier for players to find your world
- Added Random Community World list
  - This allows smaller worlds to get a chance in the spotlight

- Passageways can now be used in Private Worlds and Community Worlds!
  - Passageways can link two maps in a world, as long as the texture and paint color matches, and the directions are opposite
-# for example, an east-facing passageway in one room will link to a west-facing passageway in another room
- Added "Advanced Options" menu for more control in your Private Worlds/Community Worlds
  - You can remove/add the lobby for more immersion
  - You can enter creative mode if you are stuck
  - You can warp to any other room
- Added support for moving a room to another grid position

- Team Win block works with Hider and Seeker teams
- Rooms have terrain by default

- Player List is available on the Suburb Tech Web
- Navigation Signpost is available on the Suburb Tech Web
- Passagways are available on various Tech Webs
- Added 4x4 Warp Portal (Research Facility tech web)
- Added World Fuel Block (Game Modes tech web)

- Added Hedgehog pet

**Changes**
- Drastically reduced fuel cost of extra rooms in Community Worlds
- Unvisited rooms look more faded on World Map
- Rail Pillows count as their own restriction group
- If you are in a room with no lobby, you are told how to leave (by holding the left menu button)
- New SFX for restoring your streak
- New SFX for adding/removing saved outfits
- Higher limit for Team Bubble Setters

**Fixes**
- Fixed terrain not flattening when changing the lobby direction
- Fixed being able to clip into Desert lobby entrance
