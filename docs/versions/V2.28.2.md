# v2.28.2 - Paint Wars Patch 2
==========================
**Changes**
- Tractor Beams still apply acceleration when you have Creative Guard on
- The Reset Items block now uses the same loading restrictions as the dispenser
- Items can no longer be grabbed from the loading slot of the Reset Items block (like the dispenser)
- Anyone can drink any color paint in the Impostor game mode regardless of team and no one can stop you (to prevent giving away who is on the impostor team)
-# You only get the paint resource if your team matches the paint color, otherwise you are just paint-larping

**Fixes**
- Fixed not being able to log-in in some cases
If you've been having trouble logging in please try this new version! While these changes don't address every case where login fails, it might address yours. Keep us posted in https://discord.com/channels/1197017602292207666/1228024611405435002 if you're still having trouble logging in on this new version.

- Fixed Fullscreen Text Broadcaster blocks having a cooldown in rooms other than the wilds
- Fixed the Reset Items block not saving its loaded item
- Fixed the Paint Jar not accepting charms
- Fixed Sawblade Trap having pink instead of black
- Fixed a crash when balancing teams and all teams have a max player count of 0 due to game rule signs
- Fixed variable channels sometimes getting stuck (which can cause the Variable Canvas Count Setter to not work if you were trying to use it when the bug was happening)
