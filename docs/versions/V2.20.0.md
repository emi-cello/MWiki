# v2.20.0 - Superhero Update
==========================
**Features**
- Added Item Supercharger
- Added Item Superpowers System
  - Each item reacts to different superpowers in different ways
- Added 40+ superpowers, including:
  - Basic stat multipliers like damage, knockback, and usage cost
  - Firing projectiles like sawblades, cannonballs, and missiles
  - New mobility options like a dash or a double jump
  - Giving you potion effects like speed or invisibility
  - VFX like sparkles or trails
  - Melee combo effects to reward skillful combat
  - Shooting elemental blasts like fire or ||lightning||
  - Launching gigantic chargeable fireballs
  - Shooting laser beams
  - And way more!

**Public World**
- Added Hero Headquarters (with 5 butt-coin stashes)
- Capture the Flag is accessible from the minigame hall (there's still plenty of time if you still have PUMA achievements to finish!)
-# it will be easier to get to the map in the near future

**Changes**
- Customized items can be loaded into other items
- When "Allow Eating Unowned Items" setting is disabled, you can't eat items you are customizing (or applying superpowers to)

- Plush Pads become reinforced when a plush is in them

- Terrain Shapers can be used in dispensers
- Knockback protection activates sooner when taking strong knockback
- No knockback protection alerts if you apply knockback to yourself

- You can access the Advanced Settings in Wilds to return to the lobby easily
- Nametags always appear on invisible players in Creative Mode
- Nametags do not appear when taking thumbnail photos

**Fixes**
- Fixed Key Cards not saving in Team Bubble Setters
- Fixed CW staff not being able to kick players in some cases
- Fixed being able to keep game rules between maps
- Fixed NPC dialogue persisting between maps
