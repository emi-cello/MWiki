# v2.24.0 - Sus Update
==========================
**Features**
- Added Impostor Mode
  - In this mode, teams are hidden
- Added Elimination Vote Table
- Added ghosts
  - Ghosts cannot pick up items or blocks
  - Ghosts cannot be heard by other players
  - Ghosts can still complete tasks that require items by walking up to it
- Added achievement for playing rounds of Impostor

- Added Portal Gun
  - Portals can be placed on any wood block
  - Portals will clear when you pass through a player gate
- Added Alien Transformer Gun
- Added Rift Portal block
- Added Plasma Disc
- Added Boomerang Beam Blade
- Added UFO RC Toy
- Added 4x4 Tractor Beam

- Added Task Pad
- Added Push Button Task
- Added Item Accepter Task
- Added Pull Cord Task
- Added Swipe Card Task
- Added Scan Plate Task
- Added Target Task
- Added Task Control Block

- Added Wooden Asteroid Cannon
- Added Wooden Laser Turret
- Added Stuffed Laser Turret
- Added 1x1 and 2x2 Targets

- Added Alien Decorations
  - New alien bushes
  - New alien flower
  - Goop

- Added One-Way Vent
- Added Ghosts Game Rule
- Added Ghost Team Definition
- Added Max Initial Seekers Rule
- Added Team Text Broadcaster
- Added Variable Player Count Setter
- Added Variable Team Player Count Setter

- Added Alien Bundle
- Added Alien Portal Ball reskin
- Added new colorful spacesuit cosmetics

**Changes**
- All game modes that choose seekers are now compatible with "Max Initial Seekers" rule
- Added “lock” port to Superhero Door and Airlock Door (blue port)
- When balancing teams, teams that are assigned to hider/seeker are not included
- When balancing teams, players who are on a hider/seeker team will not be rebalanced
- Team limit rule can go to 0
- Double jump superpower resets when landing on a rail/grabbing a zipline

**Public World**
- Added S.U.S. Station
- Connected Laser Tag to other minigames

**Fixes**
- Fixed nametags being visible through walls
- Fixed charms not spinning on Frisbees
- Fixed some Moon Geodes disappearing when far away
- Fixed lives display sometimes appearing when there's only 1 life
