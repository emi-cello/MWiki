# v2.28.3 - Paint Wars Patch 3
==========================
**Features**
- Paint Jar becoming invisible when empty and decorated with charms is officially supported now
-# || Fun fact: the original way it happened relied on undefined behavior in the Unity engine and could break at any moment if Unity updated their code. But then loaf fixed it and re-implemented it from scratch. You’re welcome. ||

**Changes**
- Paint cost meter appears even when No Items rule is active
- Team Remote Stuffing / Paint Dispensers give stuffing / paint to teamless players when the dispenser is on an undefined team

**Fixes**
- Fixed Reset Item Block not reducing the item to its base form
- Fixed Reset Item Block not destroying reskins of an item
- Fixed not being able to apply Paint Usage Cost superpower to button-activated superpowers
- Fixed Paintball Gun not using Paint Usage Cost superpower correctly
- Fixed ghosts being able to use Stuffed Cannons
- Removed description on Private World/Community World return portal
- Fixed the non-functional wiring port on the bottom of the Paint Wars Results Console
- Fixed the Spray Can becoming off center after scaling it down and scaling it back up in your belly
- Fixed that periwinkle face on the inside of the Team Remote Paint Dispenser
- Fixed a case where getting jumpscared left you stuck permanently with the quicksand / acid / paint effect
- Fixed the Pull Cord Task block not having a wiring output port out the back on it’s model
