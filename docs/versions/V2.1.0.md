# v2.1.0 - 2.0 Expansion Drop
==========================

**Features**
- Added Compass gadget to help find passageways and butt-coin stashes
- Added ability to pay gnomes to switch the weekly time machine map
- Added Terrain Blocks to their respective biome Tech Webs
- Added rectangular Terrain Blocks to the Prop Tech Web for custom out-of-bounds building
- Added Terrain Paint Brushes to spice up your terrain (normal paint brushes can also be used)
- Added Custom Title Text sign
- Added Close Server Block
- Added Building Starter Pack
- World Map shows names for transition maps
- Added proper cave ambiance
- Added SFX for Levitation and Slow Falling potions
- Added SFX to purchasing VIP
- Added SFX to donating fuel
- Added SFX to Campfire
- Added SFX when a mob eats something
- Added SFX for community world earnings cash out
**Changes**
- Added Rat and Rat King to Research Facility Tech Web
- Players cannot accidentally eat items they don't own (can be disabled in advanced settings)
- Large buttons should be easier to press
- Copying a map shows map dimensions when they aren't the default
- Pasting a map shows map dimensions if it's a mismatch
- Fast Travel prompt disappears when walking away from the World Map
- Terrain Shapers can be used in the Wilds
- Renamed On Start Block to On Load Block
**Fixes**
- Fixed vote broadcaster not working properly
- Fixed being able to shoot Sawblade Launcher when it's in a wall
- Fixed incorrect language on Terrain Copy Paster prompts
- Fixed not being able to Quick Craft terrain blocks
- Fixed No Mob Raids rule not being on tech web
- Fixed LODs being to aggressive on Boxing Glove
- Fixed Basement ambiance not updating properly
- Fixed certain mob raids being broken
- Fixed glowing liquid looking wrong
- Fixed hearing life break SFX when entering Hide and Seek rooms
- Fixed Stuffing Dispenser buttons not being disabled when in one-handed mode
- NPC gnomes are oriented properly when using the Prop Scanner
