# Version 2.23.0


# v2.23.0 - Space Biome Update
======================
**Features**
- Added Space Biome
- Added Custom Gravity Selector
  - Gravity settings affect everything, including players, mobs, items, projectiles, and ragdolls
- Added Gravity Zones
- Added support for gravity in variable directions
- Added support for zero gravity

- Added Magnet
- Added Magnetized Blocks
- Added Sticky Black Hole Bomb
- Added Black Hole Bomb Pillow
- Added Beam Blade
  - Available in standard, short, dual, and crossguard variants
  - Beam color can be changed by customizing the item
  - Beam Blade can deflect lasers from mobs or the Laser Blaster
- Added Laser Blaster
  - Projectile color can be changed by customizing the item
- Added Jetpack
- Added Asteroid Spawners
  - Asteroids have health and can be destroyed
- Added Airlock Door

- Added Laser Tag game mode
  - Whoever scores the most points wins
  - Uses the game mode sign's color to determine which token value to use
  - Added achievement for playing games of Laser Tag
- Added Laser Tag Gun
- Added Laser Tag Superpower
- Added Laser Tag Ray Superpower
- Added Max Lives game rule
- Added Game Mode Leaderboard
- Added Thruster Superpower

- Added Alien Hopper mob
- Added Alien Eye mob
- Added Moon Rock Blocks
- Added 28 new space-themed props
- Added 9 new space-themed terrain decorations
- Added Astro Gnome NPC
- Added Astro Gnome Statue
- Added custom Rocket Passageway

- Added 6 new paints (Amber, Steel, Light Steel, Cadet, Midnight, Rose)
- Added Glowing Blue Paint
- Added Black Hole Paint which removes light

- New fish: Glorp
- New pet: Alien
- New record: Orbital Flow
- Added new Space Biome cosmetics
- Added Space Marine bundle
- Added Impulse Gun (confetti gun reskin)

**Public World**
- Added Spaceport map (built by the Toaster Trio)
- Added Moon Base map (built by the Beavers) - w/ butt-coin stashes
- Added Gnomeship II hang out map - w/ butt-coin stashes
- Added Laser Tag minigame (built by the Yeeps Who Don't Sleep)
- Added Space Wilds (built by Blast Off Billy)
- Removed lives from OG Hide and Seek maps

**Changes**
- Knockback multiplier superpower cannot go higher than 2x in Wilds/Freebuild
- Better physics when players are small
- When a map has no floor and zero gravity, you die on all sides
- Reduced knockback of laser beam
- Cloud blocks can be placed on air
- Double Jump superpower detaches you from minecart rails
- Mobs can break breakable wood
- Removed cooldown on Text/Vote Broadcasters (except in Wilds)
- Fuse superpower supports longer times
- Slight tuning improvements to note blocks
- Added explanation message when an item has a superpower

**Fixes**
- Fixed flying by sticking items into a minion and then kiling the minion
- Fixed game mode items sometimes not loading (e.g. Prop Scanner in Prop Hunt)
- Fixed minions not taking damage based on damage multiplier gamerules
- Fixed minions not taking extra damage from Fire Axe when on fire
- Fixed sometimes not being able to use Warp Portals when the map has just loaded
- Fixed it being hard to take off Wrist Wings and Boost Capes
- Fixed default cooldown for Shoot Harpoon superpower being too low
- Fixed record art flipping in left hand
