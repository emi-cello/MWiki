- Fixed mob spawn eggs not being allowed in backpacks, holsters, and fanny packs

- Fixed being able to rapidly turn on and off the Storm to create a strobe light
- Fixed Pellet Gatling Gun being able to shoot through walls
- Fixed a case that prevented users from loading into certian rooms
- Fixed Glorp not having pupils
- Fixed being able to start a bulk color change prompt in one room and finish it in another
- Fixed the Archer Bow challenge not working (for next time!)
