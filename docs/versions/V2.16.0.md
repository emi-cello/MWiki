# Version 2.16.0


# v2.16.0 - Deep Sea Update
==========================
Yeeps goes deep in more ways than one!
**Features**
- Added Crabbing
- Added Crab Cages
  - Place a Crab Cage in water at least 4 blocks deep and then wait for a bite
  - Crabs take longer to bite than fish so be patient!
  - Crabs don’t like to get caught so you might need to chase after them
- Added 45 creatures to catch in Crab Cages
- Crabs show up in the Fish Catalog
- Crabs can be put in the Fish Bucket
- Dobbers, Nibblets, and Clownfish can be used as bait to catch rare crabs

- Added Shark Horror Mob
  - Swims circles at the surface of the water around Horror Patrol Points
  - Has a nasty jumpscare
  - Likes to eat yeeps, especially when they are distracted by their Crab Cages
- Added Shark Spawn Egg

- Added Harpoon Gun
- Added Harpoon
- Added Stuffed Naval Mine
- Added Wooden Naval Mine
- Added Lighthouse Light block
- Added Kelp blocks
- Added Climbable Chain blocks

- Added the Ultimate Crab Crown Cosmetic
- Added 4 new crab cooking recipes
- Added 2 new fish species (20 variants total)

- Added World Token system
  - Allows for Community Worlds to add replay ability and greater depth
  - Each world has its own tokens, and tokens save between maps and across sessions
  - Map makers can fully customize how their tokens are earned and used!
- Added World Token Set block
- Added World Token Cost block
- Added World Token Threshold block
- Added World Token Broadcaster Team block
- Added World Token Daily Reward block
- Added World Token Time Bound Reward block
- Added Token Room Leaderboard
- Added World Token Exchanger block
- Added Max Tokens Sign block
- Added 2x2 and 4x4 World Token Gate
- Added World Token Teleporter block
- Added World Token Item Accepter block
- Added Player Death Token Trigger
- Added Player Win Token Trigger
- Added Mob Kill Token Trigger
- Added Player Kill Token Trigger
- Added Token Barriers
- Added VIP Barriers

- Added Worlds Tech Web
  - Added icon blocks to Worlds Tech Web
  - Moved VIP and Staff blocks to Worlds Tech Web

- Added Poseidon Bundle w/ Trident (spear reskin)

**Public World**
- Expanded Fishy Harbor:
  - Added crabbing area
  - Added a Shark
  - Added a lighthouse
  - Added a beginner Tech Web for fishing
  - Added beginner achievements for fishing
  - Adventure portal takes you to Gnome Capital so that it's less confusing on where to go
- Fishy Harbor is now one of the beginner minigames!

**Changes**
- Fish Buckets can be put in dispensers
- Radioactive signs are in signs category
- Added SFX for putting bait on Fishing Rod
- Freeze Gloves do less damage to unfrozen players
- VIP and Staff buttons/teleporters are in a new imagination category (with tokens)
- Mob Death Tracker is now called Mob Kill Tracker
- Improved game security
- Updated ToS
- Experimental tutorial changes (only some players will see them)
- Added Crab/Fish buttons to Fish Catalog for quick scrolling
- Scrolling on Fish Catalog loops

**Fixes**
- Fixed some game rules not updating correctly when painting them (like Max Stuffing Rule)
- Fixed "rule" blocks not having a consistent naming scheme
