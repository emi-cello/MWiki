# Version 2.17.0


# v2.17.0 - Maker Kit Drop
==========================
**Features**
- Added in-game rewards for Yeeps Maker Kit
  - If you pre-order a Yeeps Maker Kit, you'll get an email with your promo codes shortly after placing your order!*
-# *if you already pre-ordered the Maker Kit, you'll receive your codes later today - though it will take a few hours before all the emails go out
- Added support for Plush items and cosmetics
- Added Plush Frisbee
- Added Plush Bat
- Added Plush Sticky Impulse Bomb
- Added Plush Blue Sleep Cap
- Added Plush Red Sleep Cap

- Added Plush Pad
  - Every Yeeps Plush order now gives you the Plush Pad as a bonus in-game item!*
-# *if you already own a Yeeps Plush, you automatically get the Plush Pad when you log in
- Added Plush Pad movement system
  - A Plush on a Plush Pad will slide around within the pad
  - A Plush on a Plush Pad will be protected from a few hits of knockback before popping off

**Fixes**
- Fixed sometimes being able to use items from Team Bubble Setters after leaving the room they were from
- Fixed weird behavior when using Quick Craft while something is in your hand
