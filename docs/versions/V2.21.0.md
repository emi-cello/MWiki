# v2.21.0 - Villain Update
==========================
**Features**
- Added Minions
  - Minions can attack other players or mobs
  - Minions can take damage and receive status effects
  - Minions can be fully customized (including with charms)
- Added Laser Minion
- Added Energy Ball Minion
- Added Lightning Minion
- Added Minion Controller

- Added Wrist Web Shooter

- Added Orbital Strike Superpower
- Added Tornado Superpower
- Added Energy Ball Superpower
- Added Multishot Superpower
- Added Power Cooldown Superpower
- Added Shoot Webs Superpower

- Added Breakable Wood blocks
- Added Explodable Rock blocks
- Added Meltable Metal blocks
- Added Zappable Server blocks
- Added Token Pickup
- Added Token Crate

- Added Evil Rubber Chicken
- Added Whoopee Cushion
- Added Vat of Acid
- Added Control Panel prop

- Added Evil Scientist Bundle
- Added Evil Chainsaw
- Added Villain Freeze Ray

- Added blank gadgets to use as a base for customization and superpowers
  - Added Blank Gun
  - Added Blank Stick
  - Added Blank Helmet
  - Added Blank Wrist Box
  - Added Blank Palm Shooter

- Added 19 new charms
  - 10 new gun barrels
  - 4 new canisters
  - Targeting sight
  - Tesla coil
  - Ammo magazines
  - Styrofoam cube

- Added Creative Guard setting
  - Accessible from Advanced Options
  - In Wilds, it will automatically disable if you start hitting other players or breaking other people's blocks
- Removed cooldown when teleporting to spawn in Wilds

**Public World**
- Added Villain Lair (5 new butt-coin stashes)
- Added classic minigames layout
  - Added ||Starter House||
- Added new charms to Studio

**Changes**
- Most game rules can be toggled with a wiring input
- Loadout Setter has a reset wiring input
- Loadout Setter lets you use unowned items if they are from the map
- Loadout Setter accepts horror keys
- Item Accepters can accept charms

- Bullets ricochet more times when fired from a Revolver
- Worn items only let you use their superpowers when worn
- Laser Beam superpower does less damage and hits less often
- Mini Missile superpower costs less stuffing
- Mini Missile superpower has less cooldown
- Hot Cocoa costs 300 stuffing
- Hero Headquarters gives fewer mob loot drops

- Superpowers and charms face towards you on Tech Web and in imagination (for easier viewing)
- Records have a new orientation in bubbles
- Removed Night Lights
- Faster cape flap animation

**Fixes**
- Fixed bug with tanks shooting too many projectiles
- Fixed Freeze Ray being unable to freeze fast moving targets sometimes
- Fixed food looking weird on item displays
- Fixed Warp Portals not linking correctly when facing downwards
- Fixed items losing superpowers when put into a Charms Bench
- Fixed Item Supercharger playing SFX twice sometimes
- Fixed alarm light bypassing Epilepsy Safety setting

- Slight performance improvements when loading into maps with tons of customized items
- Improvements to startup time
